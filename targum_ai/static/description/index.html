How It Works

Simple three-step process to transform your product catalog

1. Export

Export your products from Odoo to the Targum AI platform with a single click

2. Enrich

AI analyzes and enriches your product data with enhanced descriptions and attributes

3. Import

Sync the enriched products back to your Odoo catalog automatically

Requirements

  • Odoo 17.0 or later
  • Targum AI subscription

Installation

  1. 1 Install the module through the Odoo Apps interface
  2. 2 Go to Settings → General Settings
  3. 3 Find the "Targum AI" section and configure your instance URL
  4. 4 Set up API keys and integration secrets as instructed
  5. 5 Save configuration and start enriching your products!
