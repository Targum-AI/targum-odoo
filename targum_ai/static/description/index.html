Targum AI Integration

Import products to Targum AI for enrichment and sync back to Odoo

Key Features

  • Product Export: Export products from Odoo to Targum AI platform
  • AI Enrichment: Automatically enrich product data using AI
  • Data Sync: Import enriched products back to Odoo seamlessly
  • Easy Configuration: Simple setup through Odoo's settings interface

Benefits

  • Improve product data quality
  • Increase sales through better product presentation
  • Save time on manual product management
  • Streamline product data management workflow

How It Works

1. Export

Export your products from Odoo to the Targum AI platform

2. Enrich

AI analyzes and enriches your product data

3. Import

Sync the enriched products back to your Odoo catalog

Requirements

  • Odoo 17.0 or later
  • Targum AI subscription

Installation

  1. Install the module through the Odoo Apps interface
  2. Go to Settings → General Settings
  3. Scroll down to find the "Targum AI" section
  4. Set your Targum Instance URL (e.g., https://your-targum-instance.com)
  5. Copy the generated API key
  6. In Targum Nova, create an Integration and paste the API key as the Merchant secret
  7. Generate an API token in Targum and copy it to the Integration Secret field in Odoo
  8. Save the configuration
